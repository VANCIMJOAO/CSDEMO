═══════════════════════════════════════════════════════════════════
🎯 COMO USAR NO DIA DA LAN:
═══════════════════════════════════════════════════════════════════

PASSO 1: Iniciar o Sistema
───────────────────────────
$ ./start_lan_party.sh

PASSO 2: Configurar CS2 (UMA VEZ)
──────────────────────────────────
No console do CS2:
> demo setdirectory "/home/vancim/cs2analyzer/demos"

PASSO 3: Gravar Partidas
─────────────────────────
Antes de cada partida:
> demo record nome_da_partida

Depois da partida:
> demo stop

PASSO 4: Ver no Dashboard
──────────────────────────
Acesse: http://localhost:8000
Aguarde até 30 segundos
Partida aparece automaticamente!
Click no card para ver detalhes completos

🚨 SOLUÇÃO DE PROBLEMAS:
═══════════════════════════════════════════════════════════════════

Demo não detectada?
→ Aguarde até 30s
→ Verifique se está em /demos
→ Veja logs no terminal do servidor

Servidor não inicia?
→ source venv/bin/activate
→ pip install -r requirements.txt
→ Verifique porta 8000 livre

Dashboard não atualiza?
→ Ctrl + Shift + R (force refresh)
→ Verifique console (F12)
→ Confirme que monitor está rodando
