# Pasta de Campeonatos

Esta pasta é detectada automaticamente pelo sistema.

## Como usar:

1. Crie uma subpasta com o nome do seu campeonato:
   ```
   campeonatos/alcans-santosgames/
   campeonatos/domingo-2025/
   ```

2. Coloque as demos do campeonato dentro dessa pasta

3. O sistema vai:
   - Processar as demos normalmente
   - Contar nas estatísticas gerais
   - Criar uma página específica do torneio com stats isoladas

## Exemplo:
```
campeonatos/
  └── alcans-santosgames/
      ├── semifinal_1_dust2.dem
      ├── semifinal_2_inferno.dem
      └── final_mirage.dem
```

Pronto! O torneio "Alcans SantosGames" aparecerá automaticamente no sistema.
